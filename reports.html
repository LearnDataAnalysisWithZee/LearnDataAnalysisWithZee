Researching Reports For Training Agents

Operational Training

  • quotes today
    • query: product/product type
    • result: conversation scripts for each product/product type to be stored inside the agent toolbox (check data analysis ladder for more information on the recommended structure of a conversation script)
  • client query
    • query: client query against resolution
    • result:
      1. extract client query
      2. map one or more resolutions (can vary)
      3. search for keywords and enhance each conversation script
  • company query
    • query: company query against resolution
    • result:
      1. extract company query
      2. map one or more resolutions (can vary)
      3. search for keywords and enhance each conversation script
  • anomaly detected
    • query: anomaly detected against resolution
    • result:
      1. extract anomaly detected
      2. map one or more resolutions (can vary)
      3. search for keywords and enhance each conversation script
      4. create/update companywide rules and set/audit agent objectives

Commercial Training

  • advertisement channels
    • query: policy type against advertisment channel and conversion status
    • result:
      1. extract policy type
      2. map one or more advertisement channels (can vary)
      3. create basic stats-keeping list consisting of advertisement channel, product/product type, count of advertisement channel leads & conversion status, segments
      4. across the timeline combine the daily findings from stats-keeping lists into an wider stats-keeping corpus
  • quotes today
    • query: agents note against policy type & pricing event (net)
    • result:
      1. extract from agents note strictly KPIs that are related to the transfer of the product from a business to the customer e.g. quoted, membership renewed etc
      2. create KPI lists for each KPI extracted from agents note segment inside the quotes today report
      3. each list contains three segments, agents note (KPI), policy type & pricing event (net)
      4. across the timeline combine the daily findings from KPI lists into an grander KPI corpus
